# Кнопка создания заметки из модала задачи

## Суть
Добавить кнопку "+" рядом с "..." в поле "Связать с заметкой" (`TaskModal.ts:363`). При нажатии — выбор папки через `FolderSuggestModal`, создание `.md` файла с привязкой к задаче, автозаполнение `boundNotePath`.

## Что менять

### 1. `src/task-tracker/TaskModal.ts`

**Строка 363** — после кнопки `...` добавить кнопку `+`:

```ts
const noteBtn = noteRow.createEl("button", { text: "...", cls: "tm-adv-file-btn" });
noteBtn.addEventListener("click", () => { ... });

// НОВОЕ: кнопка создания заметки
const createBtn = noteRow.createEl("button", { text: "+", cls: "tm-adv-file-btn" });
createBtn.setAttribute("title", "Создать новую заметку");
createBtn.addEventListener("click", () => {
  new FolderSuggestModal(this.app, async (folder) => {
    const title = this.titleInput.trim() || "Заметка";
    const filename = title.replace(/[\\/:*?"<>|]/g, "_") + ".md";
    const path = `${folder}/${filename}`;
    // Создаём папку если нет
    const parts = path.split("/");
    if (parts.length > 1) {
      const folderPath = parts.slice(0, -1).join("/");
      if (!this.app.vault.getAbstractFileByPath(folderPath)) {
        await this.app.vault.createFolder(folderPath);
      }
    }
    // Создаём файл если нет
    let file = this.app.vault.getAbstractFileByPath(path);
    if (!file) {
      file = await this.app.vault.create(path, "");
    }
    // Заполняем поле
    this.notePathInput = path;
    noteInput.value = path;
  }).open();
});
```

## Поток данных

1. Пользователь нажимает `+` в модале задачи
2. Открывается `FolderSuggestModal` (выбор папки vault)
3. Пользователь выбирает папку → создаётся `{folder}/{title}.md`
4. `notePathInput` и `boundNotePath` обновляются
5. При сохранении задачи `boundNotePath` сохраняется в JSON store
6. В `TaskItem.svelte` заголовок задачи становится кликабельной ссылкой → открывает заметку
