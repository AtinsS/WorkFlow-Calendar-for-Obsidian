# Calendar Plugin Remastered

> Всё в одном: умный календарь, трекер задач и привычек, тайм-менеджмент и финансовый планировщик для Obsidian.

Плагин расширяет возможности классического [obsidian-calendar-plugin](https://github.com/liamcain/obsidian-calendar-plugin), добавляя мощный движок расписания на базе библиотеки **FullCalendar**, трекер привычек с аналитикой и полноценный финансовый учёт.

## Чем этот плагин выделяется

- **Один для всего:** Не нужно переключаться между 5 разными плагинами для календаря, задач, учёта времени работы и финансов.
- **Полная совместимость:** Данные хранятся в прозрачном JSON-формате и легко синхронизируются через Obsidian Sync, Remotely Save или WebDAV (Яндекс.Диск, OneDrive).
- **Полноценные уведомления в Obsidian:** Нативные уведомления Windows, дублирование на смартфон через [ntfy.sh](https://ntfy.sh/) и автоматическая проверка просроченных задач через GitHub Actions даже когда компьютер выключен.
- **Синхронизация с заметками:** Интеграция с плагином [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) и расширением Dataview через обычные `.md` файлы.
- **Мобильная поддержка:** Адаптивный интерфейс с отдельным мобильным расписанием.
- **Погода** Просмотре погоды

## Возможности

### Календарь и расписание

- Визуальные индикаторы задач и привычек прямо в сетке календаря.
- Полноценный расписание (день / неделя / месяц) на базе библиотеки **FullCalendar** с drag & drop.
- Создание задач кликом и изменение времени перетаскиванием.
- Отдельное мобильное расписание для маленьких экранов.
- Индикатор текущего времени в расписании.
- Погода на каждый день недели в расписании (Open-Meteo API, без ключей). Погода загружается для всего видимого диапазона дат.

### Задачи и тайм-менеджмент

- **4 статуса:** *Сделать* → *В работе* → *На паузе* → *Готово*.
- **Повторяющиеся задачи:** ежедневно / еженедельно / ежемесячно с настраиваемым интервалом.
- **Проекты:** группировка задач по проектам с цветовой маркировкой.
- **Таймер:** Встроенный учёт времени с автовозобновлением при перезапуске Obsidian (рекомендую установить плагин Tray для удобства).
- **Рабочие задачи:** расчёт стоимости почасовой / подённой ставки с учётом переработок.
- **Дедлайны:** дата и время, уведомления о приближении и истечении.
- **Оценка времени:** сравнение запланированного и фактического времени.
- **Привязка к заметкам:** двусторонняя синхронизация с `.md` файлами в формате Tasks.

### Трекер привычек

- Гибкая периодичность: ежедневно / еженедельно / ежемесячно с настройкой дней недели или дня месяца.
- Количественные цели для каждой привычки.
- Подсчёт стриков (серий) и индикаторы на календаре.

- **Аналитика задач и привычек:** столбчатые и круговые диаграммы по проектам.

### Финансы и аналитика

- **Доходы:** ввод фактического дохода, автоматический расчёт по ставке из рабочих задач.
- **Бюджет:** категории расходов с иконками и суммами, правила распределения.
- **Накопления:** цели накопления с процентом выполнения.
- **Цели на месяц:** отслеживание прогресса прямо на основном экране календаря.
- **Финансовая аналитика:** графики доходов и расходов, динамика по месяцам.

### Внешний вид

- Настраиваемый акцентный цвет (в настройках).
- Стеклянные панели с настраиваемым фоном и прозрачностью.
- Панель навигации в заметках через блок кода `calendar-nav` с кастомизацией стиля.


- **Панель информации** (дата, время, погода, задачи): отображается под вкладками. Можно настроить показ только на первой вкладке или на всех открытых вкладках.

## Синхронизация

### Хранение данных

Плагин хранит данные в папке `calendar-data/` в корне хранилища. Поддерживает бесшовную синхронизацию через:

- **Obsidian Sync**
- **Remotely Save**
- **WebDAV** (Яндекс.Диск, OneDrive и др.)
- **iCloud / Google Drive**

### Внешние календари (Google Calendar, Apple Calendar и др.)

1. Создайте [GitHub Personal Access Token](https://github.com/settings/tokens) (классический) со скопом `gist`.
2. Вставьте токен в настройки плагина и нажмите **«Синхронизировать»**.
3. Плагин создаст Gist с `.ics` файлом и выдаст ссылку.
4. Добавьте эту ссылку в свой календарь через функцию «Подписка по URL».
5. Включите автоматическую синхронизацию для обновления календаря при изменении задач.

### Интеграция с форматом Tasks

При включённой настройке плагин создаёт `.md` файлы для задач, обеспечивая двустороннюю синхронизацию с плагином **Tasks** и **Dataview**.

```markdown
---
task_id: abc123
title: Купить молоко
status: todo
date: day-2024-10-25
priority: medium
---
- [ ] Купить молоко 📅 2024-10-25 🛫 14:30 ⏫
```

*(Поддерживаемые статусы: `- [ ]` todo, `- [/]` progress, `- [-]` paused, `- [x` done)*

## Уведомления и автоматизация

### Локальные уведомления

| Тип | Когда срабатывает |
| :--- | :--- |
| **Напоминания** | За N минут до начала задачи (настраивается: 1 / 5 / 10 / 15 / 30 / 60 мин). |
| **Просроченные** | Мгновенно, если задача не начата в срок. |
| **Лимит времени** | При превышении запланированной оценки. |
| **Дедлайны** | За день, в день и в момент истечения срока. |

### Уведомления на смартфон (ntfy.sh)

Дублирование уведомлений на телефон через [ntfy.sh](https://ntfy.sh/) — работает даже когда Obsidian закрыт.

1. Включите в настройках **«Отправлять в ntfy.sh»**.
2. Укажите topic (по умолчанию `Calendar_Remastered`).
3. Установите приложение ntfy на смартфон и подпишитесь на этот topic.
4. Нажмите **«Отправить тест»** для проверки.

### Уведомления при выключенном ПК (GitHub Actions)

Плагин может отправлять алерты через GitHub Actions, даже когда компьютер выключен.

**Как настроить (3 шага):**
1. Включите в настройках плагина **«Синхронизация в корень хранилища»**.
2. Скопируйте папку `examples` из репозитория плагина в корень вашего хранилища и переименуйте её в `.github`.
3. Создайте [GitHub Token](https://github.com/settings/tokens) с правами `repo` и `actions:write`, и вставьте его в настройки плагина.
> *Требуется настроенный автоматический `git push` (например, через плагин Obsidian Git).*

## Панель навигации в заметках

Вставьте блок кода в любую заметку для создания панели быстрой навигации:

````markdown
```calendar-nav
schedule:Расписание
tasks:Задачи
finance:Финансы
analytics:Аналитика
```
````

Доступные ключи: `schedule`, `tasks`, `finance`, `analytics`.

Кастомизация стиля (первая строка начинается с `%`):

````markdown
```calendar-nav
%color:#fff;bg:#333;border-radius:20px;size:14px;accent:#5f99e1
schedule:Расписание
```
````

Параметры стиля: `color` (текст), `bg` (фон), `radius` (скругление), `size` (размер шрифта), `accent` (цвет при наведении).

## Установка

### Через BRAT (Рекомендуется)

1. Установите плагин [BRAT](https://github.com/TfTHacker/obsidian42-brat).
2. Откройте настройки BRAT → **Add Beta Plugin**.
3. Вставьте ссылку: `https://github.com/AtinsS/obsidian-calendar-plugin-remastered`
4. Нажмите **Add Plugin**.

### Вручную

1. Скачайте архив, либо клонируйте репозиторий.
2. Скопируйте `main.js`, `manifest.json` и `styles.css`.
3. Поместите их в папку `.obsidian/plugins/calendar-plugin-remastered/` (создайте её, если нет).
4. Включите плагин в *Настройки → Сторонние плагины*.
